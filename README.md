# Saumen Biswas — Portfolio

Personal portfolio focused on quality engineering leadership, AI-assisted testing, reliability, engineering intelligence, and measurable impact.

The root HTML, CSS, and JavaScript remain compatible with GitHub Pages. A Vinext/Vite wrapper produces the Sites deployment bundle from the same page content.

## Development

```bash
pnpm install
pnpm dev
```

## Production build

```bash
pnpm build
```
